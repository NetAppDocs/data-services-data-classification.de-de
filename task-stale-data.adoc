= Anpassen der Definition veralteter Daten in NetApp Data Classification
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification identifiziert veraltete Daten, sodass Einsparpotenziale erkannt und Governance-Risiken adressiert werden können. Die Definition veralteter Daten kann an die Anforderungen Ihrer Organisation angepasst werden, sodass veraltete Daten basierend auf dem letzten Zugriffs- oder Änderungsdatum identifiziert werden.

Veraltete Daten können anhand des Zeitpunkts des letzten Zugriffs oder der letzten Änderung definiert werden. Ein Zeitraum von sechs Monaten bis zu zehn Jahren steht zur Auswahl.

Standardmäßig gelten Daten als veraltet, wenn sie zuletzt vor drei Jahren geändert wurden.

.veraltete Daten definieren
. Wählen Sie unter Datenklassifizierung **Konfiguration** aus.
. Wählen Sie auf der Konfigurationsseite die Registerkarte **Einstellungen** aus.
. Wählen Sie unter der Überschrift „Definition veralteter Daten“ die Option *Bearbeiten*.
. Im Dropdown-Menü **Dateieigenschaft** wählen Sie aus, ob Sie veraltete Daten basierend auf dem Zeitpunkt des *zuletzt aufgerufenen* oder *zuletzt geänderten* Datums definieren möchten.
. Wählen Sie den Zeitraum für die Definition veralteter Daten.
. Wählen Sie **Speichern**.
